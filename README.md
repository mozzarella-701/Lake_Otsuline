# WETER 時刻表取り込みツール

京阪の駅時刻表PDF(文字がアウトライン化された1ページ物)から、発車時刻をCSVにする。

```
sudo apt install poppler-utils      # pdftoppm / pdfinfo
pip install -r requirements.txt
python tools/ocr_timetable.py 50522.pdf --direction 太秦天神川方面 --day-type 土休日 --out out/50522.csv --debug out/dbg
```

## まとめて取り込む
```
python tools/batch.py <PDFフォルダ> manifest.csv out
```
- `manifest.csv`（file,station,direction,day_type）は **表の見出しを見て手で書く**。PDFのTitleは当てにならない
  （例: 京津線の「びわ湖浜大津方面」がすべて「坂本比叡山口方面」と入っている）
- 出力は PDF ごとのCSVと `out/all.csv`。本数・時刻の昇順・読めない数字・未知の記号を自動で点検して表示する
- 隣の駅どうしで列車をつないだ所要時間が揃うかも、別途確認すること（京津線では全区間で1〜4分に収まった）

## 取り込み後の点検（chain_check）
```
python tools/chain_check.py out 50622:浜大津 50522:上栄町 50422:大谷 50322:追分 50222:四宮 50122:京阪山科
```
列車の進行順に駅を並べると、隣の駅との所要時間が揃うか、どの列車が終点・始発になるかを出す。
読み落としや読み違いがあると、所要時間のずれや「対応なし」の列車として現れる。
折り返し運用（近江神宮前止まり・四宮止まりなど）は記号（近・四）と一致するはず。

## しくみ
1. `pdftoppm` で200dpiの画像にする
2. 左端の黒い「時」ラベルの箱から 5〜24 時の行を検出(20行でなければ警告)
3. 行ごとに連結成分を取り、数字と右肩の記号に分ける
4. 数字は `tools/digits/` の見本と形状照合(同じ書体なので高精度)
5. 記号は `tools/marks/` の見本と照合。意味は `tools/marks/legend.json`

## 記号の意味（legend.json）
- 京津線: 市=京都市役所前ゆき / 御=御陵ゆき / 四=四宮ゆき / ▽=石山坂本線への乗換は近江神宮前ゆきのみ
- 石山坂本線: 近=近江神宮前ゆき / ○△□◇=びわ湖浜大津で京津線の太秦天神川・京都市役所前・御陵・四宮ゆきに連絡
- 記号が上下に重なる場合（例: ◇の下に近）は mark 列に `◇近` のように並べ、mark_meaning は「／」で連結する
- 備考欄の「無印」の行先はファイルごとに違う（石山寺ゆき・坂本比叡山口ゆき・太秦天神川ゆき）ので、manifest の direction と見出しを照合すること

## 新しい駅・方面を取り込むとき
- `未知の記号N` と出たら `--debug` の画像を見て、`tools/marks/<記号>.png` として保存し、`legend.json` に意味を追記して再実行
- **方面は必ず `--direction` で指定して、PDFの見出しと合っているか目視で確認する**
  (50512.pdf は Title メタデータが「坂本比叡山口方面」だが、表の見出しは「びわ湖浜大津方面」だった)
- 本数と最初・最後の時刻を、PDFの画像と見比べる
- 備考欄(「無印=太秦天神川ゆき」など)は読み取らない。意味は legend.json に手で書く

## 検証結果(上栄町・土休日)
- 太秦天神川方面 61本、びわ湖浜大津方面 60本、全て手入力の正解と一致
- 交差検証: 50522の見本だけで50512を読むと、60本の時刻は全て正解(未登録の「▽」だけ未知として検出)

## 注意
- 駅時刻表PDFの取り込み・再公開が可能かは、京阪の利用規約を確認すること
- ダイヤ改正のたびに再取り込みが必要

## 列車ごとの時刻を組み立てる（試作）
```
python tools/assemble_trips.py data/otsu_holiday_all.csv build
```
駅ごとの発車時刻を、隣駅との所要時間（中央値±1分）でつないで列車1本ごとにする。
`build/` に schema（weter-schema.sql）と同じ列の `trips.csv` `stop_times.csv` と、`lines/stations/line_stations.csv`、
折り返し運用の推定 `turnbacks.csv` を出す。終着駅の到着時刻は、発車時刻しか無いので「最後の発車＋駅間所要時間」の推定値。
土休日分の結果: 322本。始発・終着が途中の駅になる列車（近江神宮前・四宮の折り返し）は、行先の記号と全て一致した。

## いまの位置・リアルタイム時刻表（試作）
```
python tools/position.py build trains --time 10:00 --line ishiyama-sakamoto
python tools/position.py build board  --station 京阪大津京 --time 10:25 --delay 129:唐橋前:4
```
`--delay 列車ID:駅:遅れ分` は遅延投稿の代わり。投稿された駅から先の全停車駅へ同じ遅れを引き継ぐ（`--recover` で1駅ごとの回復分を指定）。
駅間の位置は「発車時刻→次駅の時刻」の線形補間。停車時間は時刻表に無いので0として扱う。
